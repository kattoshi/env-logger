# 環境モニターサーバー＆ロガー

## システム概要
本システムは、環境を計測するIoT端末から環境計測値を取得し、本サーバーのDB へ格納およびモニター、他マシンから履歴データの問い合わせが可能なシステムである。

## 仕様

### データ値
- 日付時刻
   - ISO 8601形式のタイムスタンプ
   - DBへの格納はUTCとするが、他のインターフェースでのデフォルトのタイムゾーンは、ローカルタイムを使用する
   - 秒以下は切り捨て
- 値
   固定少数点第二位を保持する

### 環境計測端末仕様
- サーバー名：env-measure.local
- マシン：M5 Stack Atom3S lite
- rest api 仕様
  - 現在環境値取得
    - パス : GET /current
    - レスポンス：
        ```json
        {
        "temp": 温度,
        "pressure":気圧,
        "humidity":湿度,
        "cpu_temp":CPU温度       
        }
        ```

### 本システム(サーバー)
- 仕様
- マシン：ラスペリパイ４
- ホスト名：env-monitor.local
- REST API リッスンポート：80(env-logger.serviceにて ASPNETCORE_URLS=http://0.0.0.0:80 を設定)

#### ロガー機能
- 毎時、0、10、20、30、40、50分に 環境計測端末へ現在環境値取得し、DB へ格納する。
  - DBエンジン
    sqlite
  - DB-Path 
     publish 後の本番稼働時は、 永続化されている /var/lib 配下の env-logger/logger.db を利用する
     テスト時は、テスト環境下に置く

  - テーブル
    - logger
      - 日付時刻(UTC) : time , 主キー
      - 温度 : tempC
      - 湿度 : humidity
      - 気圧 : pressure
      - cpu温度 : cpu_temp

#### 履歴問い合わせ対応
REST API サーバーとして、以下のサービスを準備する
- ヘルスチェック
  - パス : GET /api/health
- 最新値取得
  - パス : GET /api/recent
  - パラメタ :
    ?count=取得数&mode=モード
    - 取得数
      過去に遡って取得。省略した場合は100個
    - モード
       0 : 全レコード(省略値)
       1 : 毎時0分の値を選択
  - レスポンス:
    最新の値から過去分を時刻で降順ソートしてjson配列で返却
    ```json
    {
        "values" : [
            "ts" : 対象日付時刻,
            "t" : 温度,
            "p" : 気圧,
            "h" : 湿度,
            "ct" : CPU温度
        ]       
    }
    ```

- 履歴取得
  - パス : GET /api/history
  - パラメタ
    ?start=期間開始日付時刻&end=期間終了日付時刻&mode=モード
    - 期間開始日付時刻、期間終了日付時刻
      返却する開始日付時刻と期間終了日付時刻である
    - モード
       0 : 全レコード(省略値)
       1 : 毎時0分の値を選択
  - レスポンス
    最新の値から過去分を時刻で降順ソートしてjson配列で返却
    ```json
    {
        "piriod" : {
            "start" : 返却開始日付時刻,
            "end"   : 返却終了日付時刻
        }
        "values" : [
            "ts" : 対象日付時刻,
            "t" : 温度,
            "p" : 気圧,
            "h" : 湿度,
            "ct" : CPU温度
        ]       
    }
    ```

#### LCDモニター表示
- 機能
  ラスペリパイ４のI2Cで接続した、1602LCDキャラクターディスプレイに現在値を表示します。
- 表示書式
  １分ごとに 現在環境値取得 を取得し以下の書式で表示する
  - １行目
    `(hh:mm)9999.9hPa`
    - 項目
      - hh : 24時間制時刻
      - mm : 毎時分
      - 9999.9 : 気圧
  - ２行目
    `  99.9C   999.9%`
    - 項目
      - 99.9 : 気温(2桁,1桁)
      - 999.9 : 湿度(3桁,1桁) 
- エラー表示
  環境計測端末への接続に失敗した場合、通常表示の代わりに以下を表示し、接続が回復次第、通常表示へ戻す
  - １行目 : `Error!! Measure`
  - ２行目 : `Device Connect`

## アーキテクト
- フレームワーク
  net10
- 使用言語
  C#
- アーキテクト
  レイヤードアーキテクチャー
- 配置
  - ~/env-logger ... プロジェクトホーム
    - src .... プログラムソース(`dotnet publish -c Release` を `-o` 省略で実行すると publish フォルダへ出力される)
    - publish .... リリース物件
    - deploy .... デプロイ関連ファイル(systemdユニットファイルなど)
- サービス
  - env-logger.service として マシン起動時に起動する
  - ユニットファイルは deploy/env-logger.service を /etc/systemd/system/ へ配置して登録する
  - DBファイル格納先の /var/lib/env-logger は事前に作成し、実行ユーザーに書き込み権限を付与しておく
- ログ
  ストレージが sdcard なので、アクセスは極力少なくする
